# Audio capability and acceptance matrix

This matrix maps the six requirements groups in
`add-cross-platform-call-audio` to tests that exist in this repository and to
the remaining hardware acceptance. A passing fake or host test is evidence for
that code path only; it does not establish target compatibility or shipped
audio support. Rows explicitly call out requirements with no implementation or
test yet.

Hardware acceptance records must include the compatibility record template
(`compatibility-record-template.md`) and applicable evidence in
`acceptance-record-template.md`. Current device measurements are candidate
evidence only.

## Coverage rule

Each row's scenario list is the complete scenario set for that requirement in
the corresponding delta spec. Automated fakes and simulators establish only the
behavior they exercise; they do not satisfy physical device, actual call,
latency, endurance, target-helper, or platform support claims. Such claims need
the named hardware record and release gates in tasks 6, 7, 8, 10, 11 and 12.
A missing implementation, test, or acceptance record leaves that requirement
unverified and its support claim unavailable.
